# درب — هيكل تطبيق حجز الحافلات

هيكل أساسي لـ Expo Router وReact Native، مقسّم حسب الميزات، من دون بيانات تجريبية أو تدفقات أعمال منفّذة.

## البدء

```bash
npm install
npm run start
```

شاشات الميزات الحالية عناصر هيكلية فقط. ملفات الخدمات تعرّف العقود والأنواع، ولم تُربط بواجهة خلفية. عميل API والتخزين الآمن بنية تحتية جاهزة للربط مستقبلًا؛ لا توجد طلبات ميزات نشطة.

## التحقق

```bash
npm run lint
npm run typecheck
```

## بنية المصدر

- `src/app/`: مسارات وتخطيطات Expo Router.
- `src/features/`: وحدات الميزات ومجلداتها المنفصلة.
- `src/components/`: مكونات واجهة مشتركة.
- `src/constants/`: الثيم والنصوص الثابتة.
- `src/hooks/`: hooks مشتركة.
- `src/services/`: أساس عميل API والتخزين الآمن.
- `src/types/`: أنواع مشتركة.
